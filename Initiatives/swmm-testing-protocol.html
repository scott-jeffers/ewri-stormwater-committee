SWMM Testing Protocol

Developing comprehensive testing protocols and validation procedures to ensure SWMM model accuracy, reliability, and consistency across applications.

Overview

As SWMM and related tools evolve, establishing standardized testing protocols helps ensure model reliability and interoperability. This initiative develops procedures for validating model results, benchmarking performance, and documenting quality assurance practices.

The protocol will address unit and integration testing, benchmark models, acceptance criteria, and documentation standards that agencies and consultants can adopt for model review and approval processes.

Recent Updates

February 2026

Initiative underway. Committee is reviewing existing testing approaches from EPA, software vendors, and research, and drafting an initial protocol outline.

Key Milestones

  • Initiative launched
  • Review existing testing frameworks
  • Draft testing protocol document
  • Pilot and refine protocol

How to Contribute

Model reviewers, software developers, and practitioners with QA/QC experience are encouraged to contribute. Help define acceptance criteria, suggest benchmark cases, or review draft protocols.
